[2024] Arduino AVR Runtime Environment (AVR Assembly, ATmega Processor)

In order to make an Embedded Systems class assignment more challenging for myself, I created an AVR runtime environment for Arduino from scratch using nothing but the AVR Assembly language. This project demonstrates a custom implementation of the startup code, the interrtupt vector table, and the system clock, that would otherwise be implemented by the Arduino AVR Core.
